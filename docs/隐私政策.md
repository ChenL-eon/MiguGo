# 隐私政策

正文常量在 `lib/core/constants/app_constants.dart` 的 `AppConstants.privacyPolicy`，由 `lib/widgets/privacy_policy.dart` 渲染。登录弹窗底部只留一句凭证去向提示，句尾的「隐私政策」按钮点开就是完整正文的详情窗口，关掉回到登录页；关于页不再重复这一份（那里的隐私政策模块已删除，正文只此一处）。内容只写实现里真实发生过的事；本页与应用内展示的是同一份内容：

| 条目 | 要点 |
| --- | --- |
| 政策范围 | 没有自建服务器与中间层，数据只在本机与咪咕官方接口之间来回；账号信息如何处理以咪咕官方政策为准 |
| 登录时提交出去的信息 | 手机号、短信验证码、账号与密码都用当场下发的 RSA 公钥加密后直接提交给通行证，只存在于那一次请求 |
| 登录之后保存在本机的是什么 | 会话凭据写入系统安全存储：Android 走 Keystore，Windows 是 DPAPI 按当前用户加密的密文；原生登录落 `pacmtoken` 和通行证签发的登录票据（票据不随普通请求发送；它在登录那一次就被咪咕消耗掉，换不来第二份会话，所以应用不拿它自动续期，只留一个调试版复测入口），官方页面登录会保存页面写下的咪咕登录 Cookie，这条路径没有登录票据 |
| 关闭主窗口后常驻托盘（Windows 可选） | 设置「账户」分组里默认关闭的一项：开启后点窗口关闭只是隐藏，进程留在后台，每 45–75 分钟带本机那份登录凭据向 `c.musicapp.migu.cn` 查一次登录状态，与前台时同一件校验、不多带信息也不去新地址；后台期间不播放音频、不读文件、无统计上报，托盘菜单「退出」立即停止并结束进程，关掉开关后关闭窗口按常规退出 |
| 图形验证码 | 显示咪咕下发的原图，由本人照着输入，不识别不代答；验证码会话只在内存中，随本次登录结束丢弃 |
| 设备标识与固定请求头 | `deviceId`（Android 为 `ANDROID_ID`，其余平台为随机 UUID）只发给咪咕；`fingerPrint` 在每次启动时生成一次、本次运行内复用（不是真实指纹），`imei` / `imsi` 固定填 `h5page` |
| 本机保存的其余内容 | 设置项、搜索历史（最多 10 条，可关可清）、导入歌单及其咪咕侧匹配结果；无播放历史、无收听统计 |
| 数据流向的网络地址 | 只有咪咕自有域名，另有例外：咪咕 302 指向自己的音频 CDN，导入歌单的封面与歌单页来自来源平台，检查更新时匿名读 `api.github.com` 上本仓库的最新发布记录（不带账号与凭据） |
| WebView 里产生的数据 | Windows 上两处各有独立目录：登录目录的 Cookie 离开登录页时清除，播放器目录的会话与网页缓存不会被本应用清除；Android 跟随系统 WebView 的本应用存储，离开登录页只删除咪咕站点的 Cookie，不整份清空 |
| 日志与第三方组件 | 无统计 / 广告 / 崩溃上报组件，无日志文件，界面与提示不回显 Cookie 值；版本检查只匿名读一次 GitHub 上本仓库的公开发布记录、比一个版本号，不下载文件也不自动安装，启动时那一次可以在设置里关掉；依赖除播放、界面与网络库外，桌面端还带窗口与托盘组件，只在你的屏幕上摆本应用自己的窗口和一枚托盘图标 |
| 系统权限 | Android 清单只声明 `INTERNET`，其余前台服务与通知类权限来自播放插件；Windows 端没有权限申请，常驻托盘多出的只是任务栏通知区域里的一枚本应用图标 |
| 如何清除本机数据 | 个人中心里的「退出登录」与「切换账号」清除本机登录凭据、登录票据与账号快照、停止播放并清空队列，不动设置、搜索历史与导入歌单；要求登录的账号接口两次回绝凭据（401 / 请先登录，两次相隔 30 分钟以上）才按同样方式自动退出一次，单次回绝只提示并保留凭据，中间不会拿留存票据试换一次（那张票已经用过，换不来新凭据）；403 与公开接口的 401 不算失效；咪咕没有登出接口，退出不通知服务端，彻底清除靠系统「清除应用数据」或删除本机应用数据目录 |
